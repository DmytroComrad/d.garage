# Гараж Амедро

Бортжурнал машины: ремонты, покупки, заправки и напоминания об обслуживании. Расход, вложения и цена километра считаются сами. Работает на телефоне и на компьютере, с аккаунтами и своей базой.

Сайт: https://garage.dvoted.club

## Что внутри

- **Фронтенд:** React 19, Vite, TypeScript, свои графики на SVG. Устанавливается как PWA и работает без сети: записи копятся в очереди и уходят на сервер, когда связь вернётся.
- **Сервер:** Cloudflare Workers, Hono, D1 (SQLite).
- **Фото и таблица:** на Google Диске пользователя. В базе хранятся только текст и ссылки.
- **Общий код:** `shared/` содержит все расчёты. Сайт и экспорт в таблицу считают одним и тем же кодом, поэтому числа не расходятся.

```
shared/      расчёты, разбор чисел, бэкап, напоминания, таблица, схемы
worker/      API: вход, данные, Google Диск и Таблицы
src/         интерфейс
migrations/  схема базы
tests/       unit, API и браузерные тесты
```

## Разработка

```sh
npm install
cp .dev.vars.example .dev.vars    # и заполни значения
npm run db:migrate:local
npm run dev
```

```sh
npm test            # расчёты и API
npm run test:e2e    # браузер: компьютер и телефон
npm run typecheck
```

## Настройка

Секреты задаются через `wrangler secret put`, в репозиторий они не попадают.

| Секрет | Зачем |
|---|---|
| `PASSWORD_PEPPER` | перец для хэшей паролей |
| `TOKEN_KEY` | 32 байта в base64url, ключ шифрования токенов Google |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | вход через Google, Диск и Таблицы |
| `TURNSTILE_SECRET` | проверка на робота при регистрации |

Без Google сайт работает, а галерея и Google Таблица отключены. Письма для сброса пароля требуют платного плана Workers: добавь привязку `send_email` с именем `EMAIL` и переменную `EMAIL_FROM`.

В Google Cloud нужны Drive API, Sheets API и OAuth-клиент типа «Web application» с адресом перенаправления `https://<домен>/api/google/callback`. Приложение запрашивает только `drive.file`: оно видит лишь файлы, которые создало само.

## Безопасность

Нашёл уязвимость? Напиши владельцу репозитория напрямую, а не в публичный issue.

- Пароли: PBKDF2 с солью и перцем из секрета.
- Сессии: случайный токен в HttpOnly-cookie, в базе только его хэш.
- Токены Google: AES-GCM, привязаны к пользователю.
- Все запросы к данным ограничены `user_id`, а составной первичный ключ не даёт одному пользователю задеть записи другого.
- Запросы на изменение принимаются только со своего происхождения.
- Ограничение частоты запросов, блокировка входа после неудачных попыток, Turnstile при регистрации.
- Загружаются только изображения: тип проверяется по содержимому файла. Отдача идёт с `nosniff` и CSP `sandbox`.
